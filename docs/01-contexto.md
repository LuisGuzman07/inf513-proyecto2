# Contexto y alcance — Grupo 18B

Proyecto académico de Tecnología Web, UAGRM: «Sistematización de Herramientas Métricas para la Selección de Personal». Equipo de tres personas; no remunerado; fecha límite 15/11/2026. Este documento registra información proporcionada, no un reglamento institucional validado.

## Dos procesos

- A — talento universitario: inscripción y evaluación de titulados UAGRM sin vacante previa. La inscripción genera un expediente privado. Publicar requiere evaluación y autorización; inscribir no equivale a publicar.
- B — servicios para empresas: solicitud y evaluación de candidatos para un cargo concreto. No exigir una cuenta empresarial para enviar la solicitud.
- Funciones comunes previstas: documentos, instrumentos, evaluaciones, entrevistas, historial, informes, OCR, IA y correo. No se implementaron en esta base técnica.

## Condiciones y pendientes

SMTP/POP3 es una condición interna. El docente escogerá aproximadamente ocho RF: todavía no se conoce su selección. SMTP no demuestra POP3; el mailer log no demuestra ninguno. OCR e IA deberán verificarse como integraciones reales cuando entren en alcance.

Pendientes: criterios PPA, fórmulas, instrumentos completos, obligatoriedad de algunos documentos y permisos definitivos. No se han supuesto ponderaciones, umbrales, documentos obligatorios ni roles institucionales.

## Próxima entrega

Inscripción A → documentos privados → expediente → revisión humana → corrección con historial. Antes de implementarla se deberán confirmar los datos mínimos y las reglas pendientes que afecten ese flujo. Esta tarea no crea modelos, tablas ni permisos de negocio.
