# Grupo 18B — instrucciones del repositorio

Trabajar en esta raíz Git; frontend/, backend/ y docs/ son los únicos proyectos. No inicializar Git dentro de ellos. No modificar las fuentes externas. Las instrucciones heredadas en frontend/ se refieren a la plantilla: sus flujos de publicación, Changesets, Chromatic y push no son acciones autorizadas para este proyecto académico.

Conservar licencia y atribuciones. Mantener pnpm 9.15.4 y pnpm-lock.yaml; no actualizar masivamente dependencias. Backend API JSON Laravel independiente, PostgreSQL; sin Inertia ni starter visual. No mezclar mocks/auth demo con servicios reales. No guardar secretos en Git ni variables VITE_.

No inventar PPA, fórmulas, instrumentos, documentos obligatorios ni permisos. Documentar bloqueos y verificaciones realmente ejecutadas. No hacer commit, publicar ni push sin solicitud explícita.
